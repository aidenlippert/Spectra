# Multi-agent experiment campaign — 13 September 2026

Eleven agents explored mathematical, numerical, and verification routes, using both existing Lambda A10 instances and local computation. The strongest result is a new implementation for discovering upper witnesses directly from the frozen Hamiltonian and its supplied Hartree–Fock determinant. With the existing lower certificates, all four H4–H10 fixtures pass the 0.0016-Hartree total-energy-width target after fresh exact two-sided replay.

These fixtures already had passing intervals using expensive FCI-derived upper witnesses. The advance here is an alternative upper-discovery path that does not read those FCI coefficients or enumerate the full Fock sector up front. It does not replace the earlier lower-certificate discovery, prove scalable accuracy, or establish a new many-body theorem.

Every displayed energy is rounded for reading; the interval files retain exact rationals. H4/H6 discovery ran locally; H8/H10 discovery ran on Lambda using CPU arithmetic with one BLAS thread. These timings are individual observations on different hosts, not a controlled cross-size performance benchmark. Upper-generation times include intermediate exact upper replays but exclude the separate full lower-plus-upper replay and all historical lower discovery.

The selected-CI generator combines Hamiltonian actions with exact integer cancellation, ranks omitted determinants by signed residual coupling divided by a regularized diagonal-energy difference, and uses a sparse projected eigensolver. Floating-point selection proposes a state; integer-amplitude rounding followed by the existing exact streaming checker establishes its upper endpoint. A projected eigensolver residual is never used as a ground-state error bound. This is an implementation of established selected-CI principles, not a claim to invent selected CI.

H10 initially failed at 16,384 states, with width approximately 0.00201714 Ha. That run cost 40.088 s. The independent extended rerun cost 100.660 s in total, first passed at 66.560 s, and continued to 31,752 states. All five root refinement runs together consumed 145.898 measured run-seconds, including the unsuccessful H10 run and both complete H10 ladders. This sum excludes the other agents' experiments, setup, prior lower discovery, and full interval replays; it is not a complete campaign compute bill. No unsuccessful witness was discarded to improve the displayed first-pass numbers.

At H10's first pass the projected sparse matrix had 8,716,230 nonzeros, compared with 603,979,776 entries in a dense matrix of the same dimension. The upper checker processed 175,718,400 word/state pairs. The rapid support growth from 16 to 24,576 and the extended run reaching 31,752 explored states prevent a credible claim of fixed-accuracy scalability. Whole-run peak memory was not instrumented.

The clean multiplier comparison uses the original H6 fixture. The earlier spin-ablation preflights used nearby symmetrized Hamiltonians and are retained as preflights only. The matched restricted-Sz lower is -6.333242734124332 Ha; the full-number-X lower is -6.3332400402471665 Ha. Their generation wall times were 139.060 and 140.914 s. Both pass when paired with the new 128-state upper. Sz-weight zero is not synonymous with full SU(2) invariance. The two systems use the same scaling procedure, but added constraint columns change the numerical scaling values.

The CPU and GPU computations request different portions of the spectrum: dense SciPy `eigh` with `subset_by_index=[0,0]` versus full dense `cupy.linalg.eigh`. Three measured trials follow warmup. These are useful implementation comparisons, not matched algorithmic kernels or a general verdict on GPU eigensolvers. Assembly and reference enumeration remain CPU work; the small solve times do not describe complete discovery. Saved GPU upper endpoints are approximately -9.202521547725 and -12.287394769980 Ha.

Verification is supported by six focused passing tests, four fresh complete exact interval replays, local rehashing of every lower certificate/new upper/spectral proof, and 44 matching remote/local downloaded JSON hashes. GPU integer witnesses were separately replayed exactly. Independent agents reviewed the evidence. Python exact arithmetic is not a formally verified implementation, and none of this establishes continuum, basis-set, or experimental accuracy beyond the frozen finite Hamiltonians. Generic nested `scope` strings in the reused streaming checker still mention historical FCI discovery; the new selected-CI provenance is recorded explicitly in the top-level interval metadata and this report.

Both existing Lambda instances were used; no new instance was launched. Live inventory lists each as one A10 24 GB, 30 vCPUs, and 200 GiB advertised RAM, at $1.29/hour each. They remain active under the existing shared-use arrangement. Source snapshots, hashes, receipts, intermediate witnesses, and unsuccessful attempts are retained.

The evidence supports concentrating the next experimental wave on reducing upper-state growth and discovering sharp lower bounds without the older large SOS searches. Useful concrete combinations are adaptive orbital/selected-CI updates with every rotation error charged, geometry-aware local-plus-collective lower certificates, and a certified complement bound around a selected subspace. Each needs an explicit resource budget and original-H endpoint replay. The current Schur refusal and weak LP bounds show the missing ingredients those combinations must supply.
