# V2 proposal: learn an operator frame and its symmetry, then transfer it

## Claim to test

Use a finite, realizable class of (n)-qubit Clifford-frame Hamiltonians. There is an unknown signed Pauli frame (C) (a Clifford conjugation), an unknown interaction graph (G), and an unknown diagonal coefficient vector (lambda):

\[
H_u=C\left[\sum_{(i,j)\in G}J_{ij}X_iX_j+\sum_i h_iZ_i+\sum_a u_aP_a\right]C^\dagger .
\]

Controls (u) select a declared Pauli term. Measurements are single-qubit Pauli measurements after evolution for times (t\le T), with (N) independent shots and additive readout error at most (eta). The class is finite for fixed (n), and all coefficients, graph degree, pulse amplitudes, (T), (N), and failure probability (delta) are declared in advance.

The reusable representation has two learned components:

1. **A:** the frame/latent operator map (C) and an operator-to-operator relation table (which measured Pauli is the image of each latent generator).
2. **B:** a symmetry/graph relation: conserved parity sectors and the sparse interaction graph in the latent frame.

These are not a cache of previously solved trajectories. A new coupling (J'_{ij}), a new field (h'_i), or a larger graph instance must be inferred and predicted through A+B.

## Positive complementarity target

The baseline receives only local trajectories for each new coupling and fits every coefficient in the physical frame independently. The learned representation first pays a discovery cost on (K_0) calibration instances, then reuses A+B.

The target theorem is conditional and finite: for the declared Clifford-frame/degree-(d) class, if the calibration interventions identify the frame with probability (1-delta/2), then a new instance requires estimating only the nonzero graph coefficients, (O(nd)) parameters, rather than a dense (O(n^2)) operator table. Conditioning on correct A, parity-sector measurements from B reduce each new trajectory to the relevant invariant block. The transfer sample/computation bound should show a strict improvement whenever (d\ll n) and the baseline must estimate dense cross-terms. If A is learned but B is not, the block restriction is unavailable; if B is learned but A is not, measurements do not address the correct latent operators. The experiment must report these ablations.

This is a proposed finite-class sample-complexity result, not a claim about generic Hamiltonians. Identifiability must be tested: globally Clifford-equivalent frames that induce identical accessible distributions are one operational equivalence class and cannot be distinguished.

## Executable small experiment

Use (n=4,5,6), degree (d\le2), a randomly chosen Clifford generated by H, S, and CNOT gates, and a graph with one held-out edge. Calibration uses product states, controls on each declared latent generator, (t\in\{0.1,0.2,0.4\}), and (N\in\{100,500,2000\}) shots. A discovery learner fits (A) by choosing the frame with maximum likelihood over the finite Clifford candidate set, then fits (B) by testing which parity observables are conserved and which two-body edges explain the short-time derivatives.

For transfer, draw a new graph and new coefficients, including an edge and field values absent from calibration. Measure held-out observables and compare prediction error, shots, and wall-clock computation. Run four matched methods:

- frozen conventional baseline: least-squares local Hamiltonian fit in the physical Pauli basis;
- retrieval-only baseline: nearest calibration trajectory, with no structural inference;
- A-only learner;
- A+B learner.

Every method receives the same calibration data and transfer budget. Report discovery cost separately from reuse cost. Positive complementarity requires A+B to beat both A-only and B-only on the new graph, and to improve on the frozen baseline after amortizing calibration over at least two transfer instances.

## Falsifiers and resource accounting

The claim fails if the frame is non-identifiable under the accessible interventions, if the learned graph does not transfer to a new coupling, or if its discovery cost exceeds the reported reuse savings. It also fails if a dense baseline with the same measured data matches the A+B method after amortization.

Count Clifford candidate evaluations, matrix-vector operations, control shots, readout calibration, and all failed model-selection trials. Do not count a candidate frame, parity sector, or graph as free prior information. A finite candidate class is a deliberate boundary condition, not evidence that arbitrary physical laws are learnable.

## Relation to established results

Bairey, Arad, and Lindner prove local Hamiltonian recovery from local observables under declared locality assumptions ([PRL 122, 020504](https://doi.org/10.1103/PhysRevLett.122.020504)). The present proposal asks whether a learned operator representation and conserved-sector structure transfer to new instances. It does not claim that their theorem supplies this transfer result. The earlier quadratic closure experiment verifies the (n(2n-1)) free-fermion Lie-space count but does not learn a reusable frame; the present design therefore measures prediction and sample savings on unseen couplings, not closure size alone.

The intended output is a reusable, independently checkable representation with assumptions, confidence, and a transfer certificate. A collection of retrieved trajectories or a post-hoc latent embedding is insufficient.

## Implemented bounded law learner

`experiments/v2_laws.py` supplies a smaller executable analogue without assuming a private stabilizer or oracle. A calibration record is `CalibrationRecord(context: tuple[int,...], outcomes: tuple[int,...])`; each context is repeated an odd number (k) of times through a binary symmetric channel with known (eta<1/2). `learn(records, eta, delta)` takes majority bits, performs generic GF(2) elimination, and returns either a mask or explicit rank-deficient abstention. The certificate uses

\[
\Pr[\text{any majority error}]\le d\exp[-2k(1/2-\eta)^2],
\]

with `required_shots(d,eta,delta)` choosing the smallest odd (k) satisfying the requested bound. The result includes rank, certificate status, confidence bound, data hash, and actual XOR-operation count. `predict(mask, inputs)` is the constant-cost reuse path; all calibration shots and elimination operations remain in the acquisition cost. The supplied tests cover transfer prediction, rank-deficient abstention, and parameter validation. This establishes discovery only for the declared linear GF(2) model class; it is not open-ended mechanism discovery.
