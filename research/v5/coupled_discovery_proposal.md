# A minimal black-box experiment for coupled-structure discovery

This proposal tests acquired physical representation rather than reuse of supplied GF(2) labels. The system is a finite linear dynamical family with rational parameters, finite interventions, and noisy observations. A conventional state-space learner with the same data is an allowed baseline and may tie; the claim is about transfer and acquisition accounting.

## Hidden physical family

The learner controls and observes a four-dimensional discrete-time system

`x_{t+1}=A x_t + B u_t + w_t`, `y_t=Cx_t+ξ_t`,

with rational matrices and bounded Gaussian noise. Each instance is generated by an unknown orthogonal matrix `Q` from a declared finite set of rational orthogonal matrices and

`A=Q diag(1/2,1/3,1/5,1/7) Q^T`.

The repeated experiment contains a hidden two-dimensional invariant subspace `S=span(q_1,q_2)`. The learner receives only standard-coordinate impulse trajectories `(u_t,y_t)`; neither `Q`, `S`, eigenvectors, nor a subspace label is supplied as a feature. The input matrix is full rank and known, so four independent impulses identify the first four Markov parameters `CB, CAB, CA^2B, ...` in the noiseless case.

The second mechanism is a weak coupling operator

`K(β)=I+β P_S`,

where `P_S` is the projector onto the discovered invariant subspace and unknown `β` is selected from a finite rational set. It acts as an intervention between observation times: `x^+ = K(β)x^-`. A direct learner that has not discovered `P_S` must fit a general symmetric 4×4 intervention; a representation learner estimates one scalar `β` after projecting onto `S` and its complement.

## Three-stage protocol

1. **Representation acquisition.** Apply four independent impulses, collect `T≥8` steps, and use a rational matrix-pencil/Ho–Kalman reconstruction to estimate `A` up to similarity. Diagonalize the estimated operator and retain the rank-two spectral projector associated with eigenvalues `{1/2,1/3}`. In the noiseless finite family, the exact Markov sequence identifies this projector uniquely because the four eigenvalues are distinct and the observation/input matrices are full rank.

2. **Mechanism acquisition.** On a fresh instance sharing the same `Q` but with unknown `β`, apply one known probe state in `S` and one in `S⊥`, perform the intervention, and estimate the two projected gains. Their ratio identifies `β` with `O((1-2η)^{-2} log(1/δ))` shots under bounded sub-Gaussian observation noise. The learned projector reduces this to a one-parameter test; the direct 4×4 baseline estimates ten symmetric parameters and must receive the same probe budget and confidence target.

3. **Held-out transfer.** On a third system with the same hidden `Q` but new drift eigenvalues and a new `β`, use the retained projector and intervention form to predict the response to a withheld pulse. Success requires the predicted output error to be below `ε` on interventions not used during either acquisition stage.

## What is actually proved in the finite family

With exact observations, stage 1 recovers the invariant projector and stage 2 reduces the intervention identification problem from ten unknown symmetric coefficients to one scalar. If the stage-1 projector error is at most `α` in operator norm and the projected probe has signal margin `m`, standard perturbation gives parameter error `O(α/m)` plus the observation-estimation error. A held-out prediction has error bounded by the propagated projector and parameter errors; the bound is checked on the third system rather than assumed.

With noise, matrix-pencil recovery is accepted only when the empirical spectral clusters around `{1/2,1/3}` are separated by more than twice the confidence radius. Otherwise the learner must return `unknown` and cannot use the representation. This prevents a finite-time numerical fit from being reported as a discovered invariant. Stage-2 confidence is conditional on stage-1 acceptance; a total failure budget `δ` is allocated by a union bound.

## Necessary ablations and failure criteria

Run four conditions: frozen full-state identification, representation-only, mechanism-only, and representation-plus-mechanism. Count all trajectory and intervention shots, including discovery. Report transfer error, confidence coverage, parameter count, and total cost. The joint condition must improve the held-out system at matched confidence after amortizing stage-1 acquisition; isolated fit quality is insufficient.

The proposal fails if the projector is selected using hidden eigenvalue labels, if the third system changes `Q` without a stated alignment protocol, if the direct baseline receives fewer observations, or if the learned subspace works only on the trajectories used for reconstruction. It also fails as a scientific-discovery claim if the finite family is never expanded: success establishes a rigorous reusable-structure benchmark, not evidence that nature generally has low-dimensional invariant representations.

## Corrected tiny separation: scalar-sensor access

The parameter-count argument above is not a valid lower bound: if the admissible intervention is already known to be `I+βP_S`, a learner can often estimate `β` without explicitly reconstructing `P_S`. The following replacement uses an explicit physical access restriction instead.

Consider a two-coordinate system with an unknown invariant projector `P∈{e_1e_1^T,e_2e_2^T}` and an unknown sign `s∈{−1,+1}`. A target intervention prepares a known reference excitation and permits one scalar sensor reading, either coordinate 1 or coordinate 2. The readout is Bernoulli with plus probability `(1+s v)/2` if the selected coordinate lies in `range(P)`, and `1/2` otherwise. Full-state measurement is charged as two scalar interventions; no hidden projector label is exposed.

If the projector is transferred from a prior black-box trajectory experiment, select its coordinate and one target shot has Bayes risk `(1-v)/2`. Without transfer, a one-shot policy must choose one coordinate; under the uniform projector prior it matches with probability `1/2`, giving exact risk `1/2-v/4`. Two target shots, one per coordinate, identify which reading is informative and then estimate `s`; this is the smallest zero-error route when `v=1` and the sensor is noiseless. The decision tree is: read coordinate 1; if it is a deterministic sign result, stop; if it is a fair outcome, read coordinate 2. With `0<v<1`, the same tree is analyzed by the binary likelihood ratio, and the one-shot risk separation remains exact.

An equally informed Bayesian learner can match these risks. The separation is therefore an access-cost theorem, not an algorithmic advantage: learning `P` amortizes the coordinate-selection intervention across held-out targets. The claim disappears if a single intervention can read both coordinates at no extra cost or if arbitrary joint POVMs are admitted. Any v5 experiment must charge those resources explicitly and compare against the same restricted Bayesian optimum.
