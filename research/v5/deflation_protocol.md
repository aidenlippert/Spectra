# v5 Gaussian deflation protocol

## Fixed source family

Use a three-dimensional orthonormal frame generated by hidden independent bits (a_i\in\{-1,+1\}):

\[
 u_i=.6,r_{i-1}+a_i .8,e_{i+1},
 \qquad
 r_i=-a_i .8,r_{i-1}+.6,e_{i+1},
 \qquad r_0=e_1,
\]

for (i=1,2,3), with indices interpreted in the declared fixed coordinate frame. The learner receives scalar unit-probe readings from Gaussian covariance sources

\[
 C_j=I+\sum_{i\leq j}\lambda_i u_i u_i^T,
 \qquad (\lambda_1,\lambda_2,\lambda_3)=(10^{14},10^{10},10^6).
\]

The true frame bits and covariance matrices remain evaluator-only. A fixed dense orthogonal matrix (Q) is applied to the public sensor coordinates and is known to both sides; it prevents coordinate-index lookup while preserving scalar probes. Prefix sources (S_1,S_2,S_3) are the only permitted source changes. There is no primitive that independently switches off an arbitrary noise mode; adding one invalidates the intended acquisition advantage.

Each action selects one unit probe (v) and returns one independent Gaussian scalar (Y\sim N(0,v^TC_jv)). Count every scalar reading. Source preparation, switching, and probe calibration must have a declared cost; if they are idealized, use the same parameterized cost for every method and state that no hardware claim follows.

## Sequential resource task

The first acquisition estimates the current dominant direction (u_1) using prefix source (S_1) and null probes. Once (u_1) is retained, the learner chooses a probe orthogonal to its estimate and acquires (u_2) from (S_2). A third target then uses a probe orthogonal to both retained directions to expose a weaker signal or mode.

Use the known-prefix null test (|Y|>20) only as a declared measurement rule. Its false-positive and false-negative probabilities must be included under the exact Gaussian variance, finite precision, and direction-estimation error. The large eigenvalues are finite mathematical parameters, not free infinite signal-to-noise assumptions.

## Amortized holdout structure

Predeclare two positive net increments on fresh couplings:

1. **Increment B:** acquire (u_1) once, then evaluate a batch of fresh targets (B_b) with varying (b) but the same retained prefix/first-mode context. Compare total scalar reads against a reset learner that reacquires the predecessor for each target.
2. **Increment C:** retain the (u_2) artifact from Increment B, then evaluate fresh targets (C_c) with new coupling bits (c) but the same declared prefix source. Compare against a learner that retains only (u_1), and a from-scratch learner.

The net gain is measured after charging the initial acquisition, all failed probes, source switches, finite-precision control synthesis, and verification. A target batch is large enough to cross the predeclared break-even point but its size is fixed before outcomes. Do not reuse target observations as acquisition data for later targets unless the protocol explicitly permits and charges that reuse.

## Required baselines

Run every fresh target under:

- **Frozen:** public initial probe policy with no learned directions;
- **Exact retrieval:** lookup of previously seen bit/frame/coupling records, expected to miss on fresh couplings;
- **From-scratch:** reacquire all needed directions for every target;
- **Stateful conventional:** an equally equipped covariance/PCA or Bayesian estimator receiving the same prefix sources, scalar readings, precision, and action budget;
- **Retained deflation:** the proposed learner retaining (u_1), then (u_2), with explicit confidence regions.

The conventional estimator may tie. The claim is reusable finite-domain deflation, not superiority over optimal inference.

## Certificates and finite precision

Use a finite precision parameter, initially (eta=10^{-9}), for stored directions and synthesized probes. If (hat u_i) has angle error (	heta_i), the residual dominant variance includes

\[
 \lambda_i\sin^2\theta_i
\]

plus the control quantization and sensor noise terms. Certify target error from these residual variances and Gaussian tail bounds on fresh readings. The certificate must account for the exact (10^{14},10^{10},10^6) scales; a floating-point zero is not a null.

If direction acquisition requires waiting for an OU-like relaxation or repeated source preparation, parameterize and charge that time identically across methods. A unit-free source switch would create an artificial advantage.

## Negative controls and invalidation tests

Include these predeclared failures:

- unknown predecessor mode with only one scalar readout, where the full analogue estimator has worst-case error near (0.248) or larger;
- a deliberately mismatched sensor-access model lacking the null-test prefix, where deflation must abstain or lose its guarantee;
- finite-precision probes with insufficient (eta), where the (\lambda_1\sin^2\theta_1) leakage violates the target bound;
- a source with independently switchable mode suppression, which should be labelled an invalid extension rather than counted as success.

The evaluator may know (U), covariance, and hidden bits; learner and policy selection may not. Do not expose full covariance, eigenvectors, unknown bits, or a free calibration report. Report scalar readings, source operations, precision operations, and source-preparation time separately.

## Interpretation gate

A positive result requires both net increments to remain positive on fresh couplings, all Gaussian/precision certificates to pass, and the retained learner to beat frozen, retrieval, and from-scratch total cost at the declared horizon. A tie with the stateful conventional estimator is acceptable. The strongest valid conclusion is a resource-accounted reusable noise-deflation protocol for this finite Gaussian frame family; it is not a hardware result, a general law-discovery result, or a claim of unrestricted scientific compounding.
