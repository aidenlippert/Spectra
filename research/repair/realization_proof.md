# Exact finite-order predictive realization for the fixed workload

## Scope and assumptions

This is a construction for the declared model class only: one scalar input, \(p\) observed output ports (\(p=2\) in the workload), discrete-time, deterministic, zero-reset, strictly proper LTI behavior, and true state dimension \(n\le D\) (\(D=4\)). It uses exact input/output records and no hidden state labels, physical matrices, named latent variables, or new coupling law. These assumptions remain model-class assumptions; they are not inferred from finite data and do not certify a physical apparatus.

Write the true system as
\[
x_{t+1}=Ax_t+Bu_t,\qquad y_t=Cx_t,\qquad x_0=0,
\]
with \(A\in\mathbb R^{n\times n}\), \(B\in\mathbb R^{n\times1}\), \(C\in\mathbb R^{p\times n}\), and no feedthrough. Its Markov vectors are \(g_k=CA^kB\). The implementation accepts exact rational records; successful full-rank data binding therefore determines rational values for the first \(2D\) vectors. The sufficiency proof does not require the unknown physical matrices themselves to have rational entries.

## Hankel construction from observable Markov data

The learner first binds the measured records to Markov vectors. For a record matrix \(X\) of zero-reset input histories and output matrix \(Y\), the exact data equation is
\[
XG=Y,
\]
where \(G\) contains \(g_0,\ldots,g_{2D-1}\) as rows. The protocol requires \(\operatorname{rank}(X)=2D\), so \(G\) is uniquely determined from observable data. If this rank condition fails, the learner requests the declared reset impulse followed by \(2D-1\) zero inputs; it refuses rather than inventing unidentifiable moments.

Arrange the Markov data into
\[
H[(q,\ell),c]=(g_{\ell+c})_q,\qquad
H^+[(q,\ell),c]=(g_{\ell+c+1})_q,
\]
for port \(q=1,\ldots,p\), lags \(\ell=0,\ldots,D-1\), and columns \(c=0,\ldots,D-1\). For a true realization,
\[
O_{(q,\ell),:}=e_q^\top CA^\ell,\qquad R_{:,c}=A^cB,
\qquad H=OR.
\]
Thus \(\operatorname{rank}H\le n\). Select \(r=\operatorname{rank}H\) independent rows \(I\) and columns \(J\), with square \(K=H[I,J]\) invertible. Define
\[
M=H^+[I,J]K^{-1},\qquad b=g_{[I]},\qquad C_R=H[(q,0),J]K^{-1}.
\]
All quantities are computed from \(G\), not supplied state matrices.

## Why the construction is exact

For a minimal reachable/observable true realization, \(r=n\), and the selected factors satisfy
\[
K=O_I R_J,\quad H^+[I,J]=O_I A R_J,\quad
b=O_I B,\quad H[(q,0),J]=CR_J.
\]
Therefore
\[
M=O_I A O_I^{-1},\qquad b=O_I B,\qquad C_R=CO_I^{-1},
\]
so the learned model is similar to the true model on its observable/reachable state:
\[
z_{t+1}=Mz_t+bu_t,\qquad y_t=C_Rz_t,\qquad z_0=0.
\]
The timing is explicit: report \(y_t\) before applying \(u_t\), update \(z_{t+1}\), then report \(y_{t+1}\). A recorded preparation is initialized by replaying its controls from \(z_0=0\); no hidden state is required.

The implementation also accepts a candidate \(r\le D\) by checking
\[
C_RM^kb=g_k\quad(0\le k<2D).
\]
The difference between the true and candidate impulse responses has a realization of dimension at most \(n+r\le2D\). A linear sequence generated by a \(2D\)-dimensional realization obeys its Cayley–Hamilton recurrence. If its first \(2D\) Markov vectors are zero, every later vector is zero. Hence the accepted candidate reproduces every finite input history in the declared exact model class. This is the finite theorem; finite rank saturation without the order prior and exact moment check is only a diagnostic.

## Declared port feedback

Let a causal feedback rule use only the preserved output ports and exogenous signal \(w_t\):
\[
u_t=K_t(y_0,\ldots,y_t,w_0,\ldots,w_t),
\]
and suppose it always returns inputs in the declared bounded interface. Both systems start from their declared zero resets and have equal outputs. Induction gives equal \(y_t\), hence equal \(u_t\) and equal input histories. The already-proved input/output equivalence then gives equal \(y_{t+1}\). Their internal coordinates need not be equal. The realization therefore preserves every such well-defined port-feedback trajectory. This does not cover an unmodeled reaction–thermal coupling or a coupling that reads hidden physical variables.

## Resource dependence and boundaries

For \(p\) ports and order prior \(D\), the data-binding solve uses \(2D\) Markov vectors and requires \(\operatorname{rank}(X)=2D\). The Hankel has \(pD\) rows and \(D\) columns; exact rank selection and inversion use rational arithmetic whose cost depends on \(D,p\) and coefficient bit length. A deployed step costs \(O(r^2+pr)\) arithmetic operations for \(z^+=Mz+bu\) and \(y=C_Rz\), with \(r\le D\). The helper that replays a stored history caps it at 256 controls; this is an implementation storage limit, while streaming replay can initialize arbitrarily long declared histories at the same per-step cost.

The theorem does not establish finite-order LTI validity, exact measurements, physical calibration, sensor sufficiency, robustness to noise/model mismatch, or validity of unseen couplings. The fixed word sweep and feedback replay are regression evidence; the algebraic certificate is the \(XG=Y\) binding, reset identity, \(2D\) moment identities, and stated order prior.
