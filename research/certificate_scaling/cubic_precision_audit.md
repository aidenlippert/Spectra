# Adaptive block raw-precision audit

The new raw snapshot path was checked on the exact M4 fixture with a one-round,
full width-2 solve using Clarabel and `row-column` conditioning.  The snapshot
contains the physical free vector, residual, equality dual, and one Gram array
per retained support.  Its weighted residual reproduces the history field
`solver_residual_l1`; the reported equality violation is independently near
machine precision.  The exported rational certificate passes the production
exact verifier, and the exact residual is recorded separately from the solver
residual.

The history separates the numerical stages: raw residual, PSD clipping change,
factor rounding change, free-variable rounding change, exported numerical
residual, and exact replay residual.  These quantities are diagnostics for a
candidate generated by the floating-point solver.  Only exact replay certifies
the lower bound; a small solver or conditioning residual alone is not a proof.

The raw arrays are saved with the row list, weights, supports, solver options,
and conditioning mode, which makes the numerical result reproducible and
auditable.  Conditioning changes the numerical representation, so the
comparison test requires the initial objective to agree within solver
tolerance; it does not assert identical duals.  Scope remains the supplied
M4 Hamiltonian and the selected quadratic cone.  No claim of global SOS
optimality, chemistry-scale polynomial scaling, or universal compression is
supported by this audit.

The mixed cubic quotient and dual formulation were also exercised on M4 with
`N=2`, body-two number ideal, full blocks, and identity anchoring. Both primal
and dual routes produced exact-replay certificates and numeric bounds agreeing
within solver tolerance. The quotient is sector-specific: its linear relations
use denominator `N` for creation words and `N-1` for annihilation words, so it
must reject boundary sectors where those denominators are invalid. This is an
exact fixed-number CAR relation, not a generic linear-dependence or
chemistry-scale complexity theorem.
